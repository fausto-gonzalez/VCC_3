## About the Project

The application concept lets customers explore specialty pizzas, build their own pizzas, customize toppings, and follow their delivery progress. Promotional offers, loyalty rewards, and customer reviews support an engaging ordering experience.

This is an educational project for a fictitious client. The features below describe the intended product scope; implementation status may vary. For a more detailed description, see the [project overview in the wiki](https://github.com/fausto-gonzalez/VCC_3/wiki).

## Planned Features

- **Visual pizza builder:** Customize a pizza and preview ingredient selections.
- **Specialty menu:** Explore restaurant-created pizzas and their details.
- **Cart and checkout:** Review selections, quantities, and order totals.
- **Promotional offers:** Apply eligible discounts to an order.
- **Order tracking:** Follow progress from confirmation to delivery.
- **Loyalty rewards:** Earn and redeem rewards under the restaurant's rules.
- **Customer reviews:** Read feedback and share an ordering experience.
- **Responsive design:** Browse on desktop, tablet, and mobile screens.

## Getting Started

### Requirements

- macOS for the `open index.html` launch command.
- Visual Studio Code.
- Git.
- A web browser and internet access to clone the repository.

### 1. Clone the repository

1. Open **Visual Studio Code**.
2. Press **Command + Shift + P** to open the Command Palette.
3. Select **Git: Clone**.
4. Paste the repository URL:

   ```text
   https://github.com/fausto-gonzalez/VCC_3
   ```

5. Choose a local parent folder for the project.
6. When cloning finishes, select **Open** to open **VCC_3** in VS Code.

### 2. Open the project in your browser

Select **Terminal → New Terminal** in VS Code. From the **VCC_3** folder containing `index.html`, run:

```bash
open index.html
```

The local page opens in your default browser. Save changes in VS Code and refresh the browser to view them.

For detailed instructions and troubleshooting, see the [Installation Guide](https://github.com/fausto-gonzalez/VCC_3/wiki/02-Installation).

## Usage

1. Browse the menu or open the pizza builder.
2. Choose a pizza and customize its available options.
3. Add it to the cart and review the order.
4. Try the demonstration checkout and tracking features when available.

Use sample information for demonstration orders. See the [Usage Guide](https://github.com/fausto-gonzalez/VCC_3/wiki/03-Usage) for the intended customer journey, including rewards and reviews.
